# Unified Profile-Picture System

The Unified Profile-Picture System provides profile pictures for Mod Bots
actors.

## Development prerequisites

- Windows
- Node.js 22 or newer
- npm

## Run for development

From the backend repository:

```powershell
npm install
npm run dev:upps
```
