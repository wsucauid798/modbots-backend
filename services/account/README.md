# Mod Bots Account

Mod Bots Account provides browser-based account creation and sign-in for Mod
Bots clients.

## Development prerequisites

- Windows
- Node.js 22 or newer
- npm
- The Mod Bots backend dependencies running locally

## Run for development

From the backend repository:

```powershell
npm install
npm run dev:account
```
